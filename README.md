# DSA Patterns Tracker

A simple, visual tracker for mastering Data Structures & Algorithms by pattern — not just by random problem lists. Group problems into the core patterns (Two Pointers, Sliding Window, Binary Search, BFS/DFS, Dynamic Programming, Backtracking, and more), track your progress, and stay consistent with your DSA prep.

## Live Site

**[https://shouryajain257.github.io/DSA-Patterns-Tracker/](https://shouryajain257.github.io/DSA-Patterns-Tracker/)**

## Features

- Problems organized by DSA pattern instead of topic or difficulty alone
- Mark problems as solved / in-progress / not started
- Track overall progress across patterns
- Progress saved locally in your browser — no sign-up required
- Focused, distraction-free UI for interview prep

## Getting Started

### Use it online

Just visit the live site above — no installation needed.

### Run it locally

```bash
# Clone the repository
git clone https://github.com/shouryajain257/DSA-Patterns-Tracker.git

# Move into the project directory
cd DSA-Patterns-Tracker

# Open index.html in your browser
# or serve it locally, e.g.:
npx serve .
```
